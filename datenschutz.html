Allgemeines zur Datenverarbeitung

Wir verarbeiten personenbezogene Daten unserer Websitebesucher nur im nachfolgend beschriebenen Umfang. Als personenbezogene Daten gelten alle Informationen, die sich auf eine identifizierte oder identifizierbare Person beziehen. Rechtsgrundlage ist die Datenschutz-Grundverordnung (DSGVO) sowie das österreichische Telekommunikationsgesetz (TKG 2021).

Hosting über GitHub Pages

Diese Website wird über GitHub Pages gehostet, einen Dienst der GitHub Inc. (eine Microsoft-Tochtergesellschaft) mit Sitz in den USA. Beim Aufruf der Website verarbeitet GitHub automatisch technische Zugriffsdaten (sogenannte Server-Logfiles), etwa IP-Adresse, Datum und Uhrzeit der Anfrage, aufgerufene Seite, verwendeter Browser und Betriebssystem sowie die zuvor besuchte Seite. Diese Verarbeitung ist technisch notwendig, um die Website ausliefern zu können, und erfolgt auf Grundlage unseres berechtigten Interesses an einem sicheren und funktionsfähigen Betrieb der Website (Art. 6 Abs. 1 lit. f DSGVO).

Da GitHub Inc. in den USA ansässig ist, kann es dabei zu einer Datenübermittlung in ein Land außerhalb der EU/des EWR kommen. Nähere Informationen zu den Datenschutzmaßnahmen von GitHub findest du in der Datenschutzerklärung von GitHub unter docs.github.com/privacy.

Kontaktformular

Das Kontaktformular auf unserer Kontaktseite speichert und überträgt keine Daten über unsere Website oder einen Server. Beim Absenden öffnet sich lediglich das auf deinem Gerät eingerichtete E-Mail-Programm mit einer vorausgefüllten Nachricht (Vorname, Nachname, E-Mail-Adresse, Nachrichtentext) an unsere Adresse office@reisenberger-performance.at. Die eigentliche Datenübertragung erfolgt erst, wenn du die E-Mail in deinem Mail-Programm tatsächlich versendest, und dann wie bei jeder gewöhnlichen E-Mail direkt zwischen deinem E-Mail-Anbieter und unserem E-Mail-Provider.

Die dabei übermittelten Daten verarbeiten wir ausschließlich, um deine Anfrage zu beantworten (Art. 6 Abs. 1 lit. b DSGVO – vorvertragliche Maßnahmen bzw. Vertragsanbahnung). Wir speichern diese E-Mails so lange, wie es zur Bearbeitung deiner Anfrage bzw. zur Erfüllung gesetzlicher Aufbewahrungspflichten erforderlich ist.

Cookies

Diese Website selbst setzt keine eigenen Cookies und verwendet keine Analyse- oder Tracking-Tools. Lediglich zur Speicherung deiner Cookie-Entscheidung (siehe unten "Google Maps") wird eine technisch notwendige Information im lokalen Speicher deines Browsers (localStorage) abgelegt; das ist gemäß § 165 Abs. 3 TKG 2021 zulässig, da diese Speicherung ausschließlich der Funktion dient, die du selbst ausgelöst hast (Merken deiner Entscheidung), und keine Auswertung oder Nachverfolgung erfolgt.

SSL-/TLS-Verschlüsselung

Diese Website nutzt aus Sicherheitsgründen eine SSL-/TLS-Verschlüsselung (erkennbar am „https://" in der Adresszeile). Damit werden die zwischen deinem Browser und unserer Website übertragenen Daten gegen Mitlesen durch Dritte geschützt.
